Command

Difficulty is 64^L divided by the number of accepted variants — each “either case” letter halves the work, each “any character” slot divides it by 64. Cost scales with total attempts, so a bigger fleet buys wall-clock, not dollars. The search is geometric: median ≈ 0.69× the mean, and you need ≈3× the mean for 95% confidence. Rate default is the measured 16-bit-comb throughput on one RTX 4090. Non-letters (digits, +, /) get no case discount.
